The Ledger — ToDo List

A minimal, elegant to-do list app. Every line you write is a promise to your future self.

Live demo: https://mostafa123dr.github.io/ToDo-List/

Features
  Add new entries with a single input field
  Mark entries as done / not done
  Delete entries individually
  Filter entries by All, Open, or Closed
  Clear all closed entries at once
  Live open/total task counters
  Data persists across sessions using localStorage
  Responsive layout for mobile screens
Built With
  HTML5
  CSS3 (Flexbox, media queries)
  Vanilla JavaScript (no frameworks or libraries)
